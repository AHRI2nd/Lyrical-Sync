# AI自動同期 インストール・使い方ガイド

Lyrical SyncのAI自動同期機能は、CTC Forced Alignerを使って歌詞テキストにタイムスタンプを自動付与します。  
オプションでDemucsによるボーカル分離を前処理として使用し、精度を向上させることができます。

---

## システム要件

| 項目 | 最小仕様 |
|------|---------|
| OS | macOS 14+ (Apple Silicon), Windows 10+ (x64), Windows ARM64 |
| RAM | 8 GB（16 GB 推奨） |
| ストレージ | 必須のアライメントモデル: 1.18 GiB / 任意のDemucsモデル: 83.0 MiB（Python環境・パッケージ用の容量は別途必要） |
| インターネット | 初回セットアップ時に必要 |

> **GPUアクセラレーション**: 現在のバージョンはCPU推論を使用します。パフォーマンスはCPUの速度に依存します。

> AI パッケージのインストール時、全パッケージを OSV のセキュリティ情報と照合します。送信するのは公開パッケージ名とバージョンのみです。監査失敗・脆弱性検出時は既存環境を保持します。更新後はパッケージを再インストールしてください。古い環境では AI 整列を実行できません。

---

## ステップ1 — Python環境のインストールと更新

AI機能はアプリ内蔵Python（CPython 3.13.17、ビルド20261021）を使用するため、別途Pythonのインストールは不要です。

1. アプリ左下の **⚙ 設定** ボタンをクリックします。
2. **AI環境** タブを選択します。
3. Pythonがインストールされていない場合は、**「AI環境をインストール / 更新」** をクリックします。内蔵CPython環境とAIパッケージをまとめて準備します。
   - macOSではCPython 3.13.17 Apple Silicon版を使用します。
   - Windows x64ではCPython 3.13.17 x64版を使用します。
   - Windows ARM64ではCPython 3.13.17 ARM64版を専用ディレクトリで使用します。
4. Pythonの準備ができていてパッケージが不足している場合は、**「パッケージ自動インストール」** をクリックします。
   - 対応プラットフォーム用の固定パッケージ一覧をインストールし、セキュリティ監査を行います。
   - Windows x64では `ctc-forced-aligner` をソースからビルドするため、Visual Studio C++ビルドツールが必要になる場合があります。
   - Windows ARM64では検証済みのネイティブCPUパッケージを使い、`ctc-forced-aligner` をソースからビルドしません。
5. 状態が準備完了になれば完了です。失敗した場合は表示されたエラーを確認し、以前の環境が保持されていることを確認してください。

> **Windows x64の注意**: Visual Studio Build Tools（C++ビルドツール）がないとソースビルドが失敗する場合があります。必要に応じて [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) をインストールしてください。ARM64ではアプリが検証済みネイティブパッケージを使います。

## ステップ2 — モデルのダウンロード

1. 設定の **AIモデル** タブを選択します。
2. 以下の表を参考に、必要なモデルをダウンロードします。

| モデル | 用途 | サイズ | 必須 |
|--------|------|--------|------|
| **ctc-mms-300m** | タイムスタンプ強制アライメント | 1.18 GiB | ✅ 必須 |
| **demucs-htdemucs** | ボーカル/伴奏分離の前処理 | 83.0 MiB | 任意 |

3. モデルファイルはデフォルトでアプリデータディレクトリに保存されます。  
   カスタムパスを指定するには、**「モデル保存パス」** から変更できます。

> **おすすめ**: まずctc-mms-300mだけでお試しください。Demucsは伴奏が多い曲で精度を高めますが、処理時間が追加されます。

---

## ステップ3 — AI自動同期の実行

1. オーディオファイルを開きます（MP3、WAV、FLAC、M4Aなど）。
2. LRCエディターに歌詞を入力します。
3. 言語一覧から自動、英語、韓国語、日本語を選択します。アライメントモデルは1,130言語に対応していますが、現在アプリで直接選択できる言語はこの一覧に限られます。
4. エディター上部の **「AI自動同期」** ボタンをクリックするとアライメントが始まります。既存の文字・単語タイムスタンプがある場合は、削除前に確認が表示されます。

### 進行状態

| 状態 | 説明 |
|------|------|
| モデル読み込み中 | ctc-mms-300mをメモリに展開中 |
| ボーカル分離 | Demucsでボーカルトラックを抽出中（Demucsインストール時） |
| アライメント分析 | 歌詞とオーディオをマッチング中 |
| 完了 | タイムスタンプ生成完了 |

---

## ステップ4 — 結果の確認と修正

- 各歌詞行の横に **信頼度バッジ**（0〜100%）が表示されます。
- 信頼度が低い行は赤いバッジで表示されます。
- 修正方法:
  - 該当行をクリックしてアクティブにし、再生中に **Space** キーで手動スタンプ
  - タイムスタンプボタンを直接クリックして現在の再生位置で上書き
- 手動スタンプした行の信頼度バッジは自動的に削除されます。
- 確認が終わったら **「下書きをクリア」** ボタンで信頼度バッジを一括削除できます。

## 設定オプション

| オプション | 場所 | 説明 |
|-----------|------|------|
| 空行オフセット | 設定 → 一般 | 空行（段落区切り）のタイムスタンプに適用するオフセット秒数（デフォルト: 1.0秒） |
| モデル保存パス | 設定 → AIモデル | デフォルトパスの代わりにカスタムパスにモデルを保存 |

## よくある質問

**Q. アライメントがずれている行が多いです。**  
A. 歌詞に誤字や不要な記号（括弧、コーラス表記など）がないか確認してください。伴奏が多い曲はDemucsをインストールして再試行すると精度が上がります。

**Q. 「Pythonの準備ができていません」というエラーが出ます。**  
A. 設定 → AI環境でPythonのインストール状態を確認してください。インストール済みでもエラーが続く場合は、アプリを再起動してみてください。

**Q. Windowsでパッケージのインストールが失敗します。**  
A. Visual Studio Build Toolsの「C++によるデスクトップ開発」ワークロードをインストールしてから再試行してください。
